# ai-learning

AI 学习记录

## 项目结构

```
ai-learning/
├── client/          # Vue 3 + Vite + TypeScript 前端
├── server/          # Express + TypeScript 后端
└── README.md
```

## 快速开始

### 后端

```bash
cd server
npm install
npm run dev
```

服务运行在 `http://localhost:9527`

### 前端

```bash
cd client
npm install
npm run dev
```
